# Vikas Kumar Portfolio

Static portfolio ready for Cloudflare Pages. No build command is required.

Before deploying, copy your resume PDF into `assets/` as `Vikas_Kumar_Resume.pdf`. After Cloudflare gives you a URL, replace `https://YOUR-SITE.pages.dev` in `robots.txt` and `sitemap.xml`.

To deploy: upload this folder to a GitHub repository, then in Cloudflare Pages choose the repository, select framework preset **None**, leave build settings blank, and deploy.
